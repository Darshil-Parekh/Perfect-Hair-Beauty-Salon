# 💇‍♀️ Perfect Hair & Beauty Salon

A modern, responsive salon website designed for **Perfect Hair & Beauty Salon**. The website provides customers with information about salon services, showcases the salon through an attractive gallery, and offers an easy way to explore and book services.

## 🌐 Live Demo

🔗 https://darshil-parekh.github.io/Perfect-Hair-Beauty-Salon/

## ✨ Features

- 📱 Fully responsive design
- 💇‍♀️ Women's & Men's salon services
- 📸 Attractive image gallery
- 📅 Appointment booking section
- 🎨 Modern and elegant UI
- 🧭 Responsive navigation bar
- 💻 Mobile, tablet & desktop friendly
- ⚡ Smooth animations and interactive elements
- 📞 Contact and salon information

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Animate.css
